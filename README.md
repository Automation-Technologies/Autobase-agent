## ⚙️ Настройка

### Первый запуск

1. **Запустите** `TA-Agent.exe` (или `python launcher.py` для разработки)
2. При первом запуске появится окно: **"Придумайте новый мастер-пароль"**
   - ⚠️ **ВАЖНО**: Придумайте надежный пароль и обязательно запомните его!
   - Этот пароль нужен для всех последующих запусков
   - Без пароля данные нельзя будет расшифровать
3. После ввода пароля откроется главное окно приложения

### Настройка подключения

1. **Получите токен агента** в телеграм‑боте:
   - Откройте телеграм бота
   - Используйте команду `/token` для получения токена агента
   - Скопируйте полученный токен

2. **В главном окне приложения**:
   - Перейдите на вкладку **"Настройки"**
   - Введите **токен агента**, полученный из телеграм‑бота по команде `/token`
   - Нажмите **"Сохранить"**

### Добавление аккаунтов Steam

1. **Подготовьте файлы**:
   - `.maFile` файлы Steam Guard для каждого аккаунта
   - Логины и пароли аккаунтов

2. **В главном окне приложения**:
   - Перейдите на вкладку **"Аккаунты"**
   - Нажмите **"Добавить аккаунт"**
   - Заполните форму:
     - **Логин** - логин Steam аккаунта
     - **Пароль** - пароль Steam аккаунта
     - **maFile** - путь к файлу `.maFile` (можно перетащить файл)
     - **API ключ** - Steam API ключ (опционально)
   - Нажмите **"Сохранить"**

3. **Синхронизация аккаунтов с Ботом**:

- Используйте кнопку **"Добавить новые аккаунты в бота"** для добавления логинов новых аккаунтов в бота.
- При добавлении нового аккаунта он автоматически отправляется в DEEP Бота, а уже оттуда его можно перенести в нужного бота.


### Настройка прокси (опционально)

1. В главном окне выберите аккаунт из списка
2. Введите прокси в формате: `http://user:pass@host:port` или `socks5://user:pass@host:port`
3. Нажмите **"Сохранить прокси"**

## 📖 Использование

### Запуск агента

1. **Запустите** приложение и введите мастер-пароль
2. **Проверьте настройки** подключения (токен агента)
3. Нажмите кнопку **"Запустить агента"** на вкладке **"Dashboard"**
4. Дождитесь подключения - статус изменится на **"Подключен"** (зеленый индикатор)

### Мониторинг работы

- **Вкладка "Dashboard"**:
  - Статус подключения (подключен/отключен)
  - Лог работы агента в реальном времени
  - Кнопка для запуска/остановки агента

- **Вкладка "Аккаунты"**:
  - Список всех добавленных аккаунтов
  - Прокси для каждого аккаунта
  - Возможность добавления/удаления аккаунтов

- **Вкладка "Настройки"**:
  - Настройки подключения к серверу
  - Сохранение конфигурации

### Синхронизация аккаунтов с Ботом

- Используйте кнопку **"Добавить новые аккаунты в бота"** для добавления логинов новых аккаунтов в бота.
- При добавлении нового аккаунта он автоматически отправляется в DEEP Бота, а уже оттуда его можно перенести в нужного бота.

### Завершение работы

1. Нажмите кнопку **"Остановить агента"** (если агент запущен)
2. Закройте окно приложения (крестик)
3. Папка `maFiles` **автоматически зашифруется** при закрытии
4. Файлы получат расширение `.enc` - данные защищены

## 📁 Структура приложения

Приложение создает следующую структуру папок рядом с исполняемым файлом:

```
TA-Agent.exe            ← Главный файл
maFiles/                 ← Папка с данными аккаунтов (шифруется)
  ├── accounts.json      ← Данные аккаунтов
  └── *.maFile           ← Файлы Steam Guard
config/                  ← Конфигурация (создается автоматически)
  ├── config.json        ← Настройки токена агента
  └── proxies.json       ← Прокси для аккаунтов
logs/                    ← Логи (создается автоматически)
  └── agent.log          ← Лог работы агента
security.salt            ← Файл соли для шифрования (создается автоматически)
```

### Описание файлов и папок

- **`maFiles/`** - Данные аккаунтов Steam (логины, пароли, maFile, cookies)
  - ⚠️ **ВАЖНО**: Эта папка шифруется мастер-паролем
  - При работе файлы расшифрованы (без `.enc`)
  - При закрытии файлы зашифрованы (с `.enc`)

- **`config/`** - Конфигурация приложения
  - `config.json` - токен агента
  - `proxies.json` - Прокси для аккаунтов

- **`logs/`** - Логи работы
  - `agent.log` - Основной лог работы агента

- **`security.salt`** - Файл соли для шифрования (не удаляйте!)

## 🔒 Безопасность

- ⚠️ **НЕ ТЕРЯЙТЕ мастер-пароль** - без него данные не расшифровать
- ⚠️ **НЕ УДАЛЯЙТЕ** файл `security.salt` - без него нельзя расшифровать данные
- ⚠️ **НЕ ПЕРЕМЕЩАЙТЕ** файлы из папки `maFiles` вручную во время работы приложения
- ✅ Папка `maFiles` автоматически шифруется при закрытии приложения
- ✅ Файлы остаются зашифрованными, пока приложение не запущено
- ✅ Токен агента хранится в зашифрованном виде в `config/config.json`

## 🔄 Перенос на другой компьютер

1. Скопируйте **весь набор файлов**:
   - `TA-Agent.exe`
   - `maFiles/` (вместе с зашифрованными файлами `.enc`)
   - `config/` (если есть)
   - `security.salt` (обязательно!)
   - `logs/` (опционально)

2. На новом компьютере запустите `TA-Agent.exe`
3. Введите ваш **мастер-пароль**
4. Всё должно работать

КАК ЗАПУСТИТЬ
--------------
1. Распакуй этот архив в любую папку (диск C, D, флешка — не важно).
2. Дважды кликни по файлу start.bat.
3. Откроется окно приложения. При первом запуске задай мастер-пароль
   для защиты папки maFiles.

Никаких установок Python, никакого интернета при первом запуске не нужно.
Всё уже внутри архива.

ТРЕБОВАНИЯ
----------
Windows 64-bit. Никаких других программ ставить не нужно.

СОДЕРЖИМОЕ
----------
  start.bat          — запуск приложения (используй его)
  launcher.py        — точка входа (запускается через start.bat)
  main.py            — основное приложение
  python_portable\   — портативный Python и все библиотеки
  core\, gui\, steampy\ — код приложения
  config\, maFiles\, logs\ — создаются при работе

НЕ УДАЛЯЙ и не переименовывай папку python_portable и файл start.bat.
